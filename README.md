# Угольный Яр — Android

Игра лежит в `app/src/main/assets/index.html`, приложение — WebView-оболочка.

## Как получить APK (бесплатно, без установки Android Studio)
1. Создай пустой репозиторий на github.com.
2. Загрузи туда **всё содержимое** этой папки (включая скрытую папку `.github`):
   проще всего — `git init && git add . && git commit -m init && git push`.
3. Открой вкладку **Actions** → запуск «Build APK» (стартует сам, ~3–5 минут).
4. Когда появится зелёная галочка — открой запуск и скачай **UgolnyYar-apk** внизу страницы.
5. Распакуй zip, перекинь `UgolnyYar.apk` на телефон и установи
   (разреши «установку из неизвестных источников»).

## Через Android Studio
Открой папку как проект → Build → Build APK(s).
