ЛЕСНОЙ РУБЕЖ — игра по сети без аккаунта Claude

1. Установите Node.js (версии 16 или новее) с сайта nodejs.org.
2. Распакуйте архив в любую папку, откройте в ней терминал (командную строку).
3. Запустите:   node server.js
   Сервер покажет адрес вида  http://192.168.1.5:8080
4. Друзья, подключённые к той же Wi-Fi сети, открывают этот адрес в браузере телефона.
   В Android-приложении: Онлайн -> Сервер «По сети» -> адрес 192.168.1.5:8080 -> Подключить.
5. Сервер работает, пока открыто окно терминала. Другой порт:  PORT=3000 node server.js
   (в Windows: set PORT=3000 && node server.js)

Игра через интернет: разместите эти файлы на хостинге с Node.js (Render, Railway, свой VPS),
команда запуска — node server.js. Адрес сервера в игре — адрес сайта, например my-game.onrender.com.
Если Windows спросит про доступ брандмауэра для Node.js — разрешите для частных сетей.
